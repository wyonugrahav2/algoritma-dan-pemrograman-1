# My CLI Dashboard

Aplikasi CLI interaktif menggunakan Python dan library `rich`.

## Cara Install
1. Buat virtual environment: `python -m venv .venv`
2. Aktifkan: 
   - Mac/Linux: `source .venv/bin/activate`
   - Windows: `.venv\Scripts\activate`
3. Install library: `pip install -r requirements.txt`
4. Jalankan aplikasi: `python -m src.main`
